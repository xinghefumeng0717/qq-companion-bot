# 火山引擎（豆包语音）新手开通手册

> 调研日期：2026-10-04。面向第一次用火山引擎的所有者。结论先行：
> - **只用官方女声** → 开通「豆包语音合成模型2.0」即可，个人实名基本必定能开，20000 字符免费试用，3 元/万字符，100% 走得通；
> - **克隆专属音色** → 还需「豆包声音复刻模型2.0」，个人能否开通官方无明文，调研判断 75~85% 概率能开，按第三节按钮判据实测。

## 二、Step-by-Step

### Step 1｜注册账号
https://www.volcengine.com/ 右上角「登录/注册」，手机号/邮箱注册，也可抖音 APP 扫码。

### Step 2｜个人实名认证
https://console.volcengine.com/user/authentication/detail/ →「开始个人认证」：
- **扫脸认证（推荐）**：填姓名+身份证号 → 摄像头或抖音扫码扫脸，立即生效；需大陆居民身份证；
- 银行卡认证：同样即时通过；
- **不认证会一直在加载页转圈且无报错**——先做完这步再往下点。

### Step 3｜进豆包语音控制台
https://console.volcengine.com/speech/new ，确认左上角项目（默认 Default 即可）。**资源/密钥/账单都与项目绑定，项目间不共享**——别在 A 项目开服务、B 项目拿 key。

### Step 4｜开通模型服务
左侧「开通管理」（https://console.volcengine.com/speech/new/setting/activate ）：
1. 找「豆包语音合成模型2.0」（也可能显示「语音合成 2.0」）→ 点「开通」；
2. 要克隆再找「豆包声音复刻模型2.0」→ 同样开通；
3. 弹窗勾选服务协议 →「开通模型」。
只用官方音色的话，只开第一个就够。

### Step 5｜确认免费试用额度
豆包语音合成 2.0 / 声音复刻 2.0 各 **20000 字符、半年有效**。官方两处口径不一（快速入门说自动到账，计费概述说要点「试用」按钮）——**以页面显示为准**：看到 20000 字符就是到账，没有就点一下「试用」。免费礼包只在首次开通赠送。

### Step 6｜拿 API Key
「API Key 管理」（https://console.volcengine.com/speech/new/setting/apikeys ）→ 创建并复制。新版控制台只需一个 header：
```
x-api-key: <你的 API Key>
X-Api-Resource-Id: seed-tts-2.0   （预置音色；复刻音色用 seed-icl-2.0）
```

### Step 7｜（可选）训练专属音色
「声音复刻」体验页（https://console.volcengine.com/speech/new/experience/clone ）：
- 素材：14~30 秒、wav、安静、单人、无背景乐、情感平稳；<14s 或多人声效果差；
- 上传 → 试听确认干净 → 勾选声音复刻协议 → 启动训练 → 复制 `S_` 开头音色 ID；
- **协议要求声音本人授权**——用别人的声音必须有书面同意。

### Step 8｜调通最小请求
预置音色：`x-api-key` + `X-Api-Resource-Id: seed-tts-2.0` + 音色 ID；复刻音色：配 `seed-icl-2.0` + `S_` ID。**音色与 Resource-Id 配错会报 resource ID is not match**。

### Step 9｜转正式与付费
- 开通正式版后**试用赠送用量清零**并开始计费；欠费会关停甚至回收服务；
- 音色槽位：预付费下单时扣 138 元/音色；后付费**首次正式合成时**扣 138 元；
- 合成量费：3 元/万字符（预置与复刻同价）。

## 三、个人 vs 企业认证：结论与实测判据

| 服务 | 个人实名能否开通 | 置信度 |
|---|---|---|
| 豆包语音合成模型2.0（预置音色） | **能** | 高 |
| 豆包声音复刻模型2.0（克隆） | **大概率能** | 75~85%，官方无明文 |

**3 分钟实测法**：个人扫脸实名 → 打开开通管理 → 找「豆包声音复刻模型2.0」看「开通」按钮：可点且弹协议＝能开；置灰或提示"需企业实名"＝不能开。

**个人开不了复刻时的替代路径（推荐首选）**：只用「语音合成 2.0」+ 官方预置女声——130+ 音色（爽快思思2.0 语音闲聊、Vivi 2.0 温柔女声、甜美小源等），同为 3 元/万字符、同样 2 万字符免费，零授权风险。**对"她偶尔发语音"的场景，这可能比克隆更合适更省事。**

## 四、新手最容易踩的坑

1. 不实名就往下点 → 卡加载页无报错；
2. 鉴权两套并存：新版 `x-api-key`；旧版 AppID+Access Token。401/403 先想"服务开没开、项目对不对"；
3. 音色与 Resource-Id 不匹配（S_ 音色必须配 seed-icl-2.0）；
4. 开通与项目绑定，切项目要重查；
5. 免费额度半年有效、开通正式版即清零、试用音色 7 天未正式调用被删——别囤；
6. 第三方博客的价格（如"13 元/万字符"）多为旧价误传，**一律以官方计费页为准**（当前 3 元/万字符）；
7. 别一上来买 138 元槽位——先用 2 万字符试用验证效果再转正。

## 五、本项目最短落地路径

1. 个人扫脸实名 → 开通「语音合成 2.0」→ 拿 API Key（约 10 分钟，0 元）；
2. 官方预置女声接进 `companion/tts.py`（FIXES22 阶段 A 用 edge-tts 亦可，零依赖火山）；
3. 用 2 万字符试用验证真机效果；
4. 只有"必须是她独一无二的声音"时，才开「声音复刻 2.0」：按钮判据确认可开 → 书面授权真人录 14~30s 干净 wav → 试用满意再付 138 元转正。
