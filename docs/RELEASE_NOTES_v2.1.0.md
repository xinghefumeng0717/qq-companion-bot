# v2.1.0

语音链路重构与公开版清洗：

- **少干预**：主聊只产自然正文，不再使用次级模型整理语音格式或补写失败道歉，移除 `voice_normalize` / `voice_recovery` 套娃调用。
- **程序逐字选句**：`VoicePlanner` 从原话选择连续片段，文字与语音保持原顺序，不做二次改写。
- **失败原地转文字**：TTS 或 OneBot 投递失败时直接发送原句，不再生成新的语音承诺。
- **统一规划与真实状态**：主聊与主动消息共用语音规划、日额度和投递事实；普通文字不会冲掉最近一次真实语音事件。
- **并发防超发**：TTS 发送锁覆盖额度复查、合成、发送和成功记账。
- **公开版继续清洗**：角色卡与代码分离，仅保留 `characters/example` 通用示例卡；测试、脚本和启动器不依赖私有角色、个人档案、真实聊天数据或本机私有路径。
- **兼容性**：无新增第三方依赖，无数据库 Schema 变更，既有角色卡和 `config.toml` 仍由部署者维护。
- **验证**：1000+ 项离线测试通过；多轮全流程沙箱覆盖正常语音、故障降级、引用、沉默、记忆和重启。
