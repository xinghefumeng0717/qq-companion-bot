## 总纪律（每条 finding 都受此约束）

1. **只审不改**：发现任何问题只写报告，修复一律另立项；唯一允许的"改"是跑测试和沙箱脚本；
2. **证据强制**：每条 finding 必须带 `文件:行号` 证据与判定逻辑，**禁止凭印象、凭"感觉可能有问题"上报**；没有证据的猜想写进"悬而未决"区，不混进正表；
3. **红线只读**：`characters/`、`config.toml`、服务器一切资产只读；服务器侧仅允许明确列出的只读 SQL 与只读命令；
4. 测试全绿是入场券不是结论——552 全绿通过后才准开始审；
5. 真实 API 调用总限额 **¥2**（够用：本审查以静态审查为主，只允许个别验证性调用）；
6. 产出：按审查面分节，finding 用统一模板（见文末），末尾给**可部署 / 不可部署**总结论。
