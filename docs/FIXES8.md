## 任务 1：好感度系统重构（affection.py）

### 1.1 六维封顶与阻力修正
- `update()` 中 `dims[dim] = max(0.0, round(new_val, 2))` 改为同时封顶：`min(100.0, max(0.0, ...))`（tension 同上限 100）；
- `calc_resistance` 去除 0.15 硬底，改为 composite→100 时阻力**渐近到 0** 的单调曲线（形式自定，如 `r = exp(-k*(composite-20))` 或分段线性），参数 k 由 1.3 的节奏仿真求解；
- EMA 阻尼（ALPHA）与 delta 公式 `(raw-0.4)*4` **不动**（锚点已按此校准）。

### 1.2 阶段阈值重映射（核心求解任务）
`STAGE_THRESHOLDS` 重排到 [0,100] 内。用仿真（场景：sd=5.0, rs=5.5, wa=6.0, re=5.5，30 轮/天，6 聊 1 歇，初态用 `characters/example/character.json` 的 initial_dims）迭代求解阈值与阻力参数，使各阶段到达天数命中下表（**容差 ±25%**）：

| 阶段 | 名称 | 目标到达时间 |
|---|---|---|
| 1→2 | 熟络 | ~7 天 |
| →3 | 同好 | ~21 天 |
| →4 | 知己 | ~45 天 |
| →5 | 微酸 | ~75 天 |
| →6 | 倾心 | **~120 天（一季）** |
| →7 | 依恋 | ~210 天 |
| →8 | 深情 | **~365 天（一年）** |
| →9 | 相守 | **渐近线：仿真 3650 天不到达，且复合分曲线在 95+ 明显走平** |

- 同时验证冷淡场景（全 3.0）：复合分单调下行归零、无负数、无震荡；
- 把求解过程和最终参数写入 `scripts/sim/score_simulation.py`（扩展它，别另起炉灶），输出"目标 vs 实测"对照表；
- **相守=渐近线**这一点在 `affection.py` 的 `STAGE_THRESHOLDS` 上方写注释说明（一句话：设计上不可达，是方向不是终点）。
