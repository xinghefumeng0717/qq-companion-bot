# 迭代任务书（FIXES24）：毕业彩排——全要素真实演练场（出闸动态验收）

> 项目：QQ 伴侣机器人（D:/qq-companion）。前置阅读：`STATUS.md`、`docs/DEEP_AUDIT.md`（静态审计，本彩排是它的动态补充）、`docs/FIXES18.md`（对聊仿真器，本彩排建在它之上）。
> 背景：第二轮 V2 的 12 个迭代（FIXES12~23）各自带单项冒烟，但**从未全部同时在场运行过**。单项及格不等于同台不打架——表情×引用×沉默×typing×事件消息×语音闸门×好感度，真实场景里它们是同时在一张桌子上吃饭的。本迭代造一个"全要素演练场"：用 FIXES18 的仿真器骨架，连演 2~3 个模拟日，把第二轮所有功能逼到同一份 transcript 里，作为**总部署出闸的动态验收**（与 DEEP_AUDIT 静态审计组成双闸，缺一不可）。
>
> 所有者已拍板的决策（不许翻案，直接执行）：
> 1. 彩排是**出闸必经环节**，位置在 DEEP_AUDIT 之后、总部署之前；**全要素记分卡无 FAIL 才准部署**（N/A 允许但必须注明"本彩排未跑到，上线后首周观察补验"）；
> 2. 跨日连续仿真（时钟推进 2~3 个模拟日），不是若干独立小局——凌晨备份钩子、主线状态滚动、事件消息这些"按天长"的功能只有在连续时间里才会现形；
> 3. 裁判双轨：确定性断言（机制层）+ transcript 原文（所有者抽读，文字层终审）；
> 4. 成本熔断 ¥10（跨日 60~100 轮量级）；
> 5. 执行模型**不动 `characters/`、`config.toml`**；全程临时库、零生产副作用；施工排在 FIXES23 交付之后。
>
> 全局约束（高压线）：
> 1. 完成后 `./venv/Scripts/python.exe -m unittest discover -s tests` 全绿；
> 2. 彩排本身必须真跑一遍并交付完整证据（transcript + 记分卡 + 成本实报）；
> 3. 交付：逐项 diff 摘要 + 测试输出 + 彩排证据。

## 任务 1：跨日仿真骨架（scripts/sim/final_rehearsal.py，复用 duo_sim 的引擎接线）

1. 以 duo_sim 的全真管道为基础（TurnHandler + 七引擎 + 临时库 + 时钟伪装），新增**多日时钟推进**：时钟按剧本从 D1 傍晚推进到 D3 中午，睡眠时段跳过（22 点直接跳到次日 7 点，但**凌晨 04:17 的备份维护钩子必须真触发**——它是"按天长"的功能链的一环）；
2. 主动消息调度在每个唤醒周期真跑 `trigger_cycle`（唤醒间隔按生产配置 20~40 分钟压缩为仿真刻度），让决策层/事件通道/免打扰全部走真逻辑；
3. 预置初始状态：往临时库写 2~3 条 life_arcs（一条 key_date=D2 让它在彩排中 resolved 并触发事件消息、一条 near、一条 upcoming）、若干 diary/facts（让【她最近的生活】与记忆区块有内容）。

## 任务 2：彩排剧本（连续叙事，五幕）

- **第一幕（D1 晚 · 多轮对话）**：模拟他按真人画像聊天——连发（造引用机会）、句尾挂脸（考她读侧理解）、话题跳转；她侧考点：face 使用（≤2/轮）、引用（低频）、旁白滤网、typing 表演；
- **第二幕（D1 夜 · 告别）**：他说"睡了"→ 她收束（沉默权/短气泡）；他道晚安后又冒泡喊饿 → 考点：关照≤2 句、禁反问追逼（FIXES18 S1 两枚病灶的复验场）；
- **第三幕（D2 凌晨+白天 · 按天长的东西）**：04:17 备份钩子+主线补充真触发；D2 白天那条 key_date=D2 的主线推进到 today→resolved；**事件主动消息**在 D2 傍晚前发出（考点：脱口而出语气、日上限 1 条、计入未回复闸门）；
- **第四幕（D2 白天 · 主动消息与已读不回）**：他全程沉默，她 2~3 个唤醒周期 → 考点：决策层止损（连续未回闸门）、免打扰时段（D2 深夜周期不发送）；
- **第五幕（D3 上午 · 日常回归）**：他回来聊天 → 考点：语音闸门（`[tts].enabled=false`，模型不该认识 `[voice:]`，万一写了必须降级文字）、【她最近的生活】区块随主线状态变化（resolved 的事件应出现）。

## 任务 3：全要素记分卡（每项一行：PASS / FAIL / N/A）

机制层确定性断言（**期望方向必须每条显式写 expect**——STATUS 经验 14）：

| 要素 | 断言（示例方向，执行模型补全） |
|---|---|
| face 双向 | 她全程有用脸（>0）、每轮 ≤2、无清单外标签 |
| 引用回复 | 有引用机会时出现过引用、每轮 ≤1、无越界编号 |
| 沉默权 | 告别场景出现 [沉默] 且全部合规（他纯语气词/表情承接告别） |
| 旁白滤网 | 全程无整行旁白上屏（或滤网 INFO 日志在案） |
| 事件消息 | D2 事件消息实发、仅 1 条、决策层调用 0 次（事件通道抢先） |
| 主动消息 | 免打扰时段 0 发送、连续未回闸门生效后 0 发送 |
| 语音闸门 | 全程 0 条 record 段出站（默认关）、[voice:] 若出现必降级 |
| 生活主线 | 【她最近的生活】区块随状态机变化（near→today→resolved 至少出现一次变迁） |
| 数值引擎 | 彩排前后 affection/mood 变化方向符合规则（有对话涨、冷落降），无异常跳变 |
| 风格基线 | 称呼率、气泡长度中位、句尾问号率在生产基线区间内（benchmark 口径） |
| 成本 | 全程实报 ≤ ¥10 |

N/A 纪律：本彩排没跑到的要素标 N/A 并写明"上线后首周观察补验"——**不许把"没跑到"写成"通过了"**（零观测≠合规，前科累累）。
