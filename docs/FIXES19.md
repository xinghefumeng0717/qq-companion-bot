## 任务 1：整行内心旁白滤网（companion/replier.py）

1. 新增模块级函数 `drop_inner_narration_lines(text: str, source: str = "reply") -> str`，结构、日志、docstring 风格对齐旁边的 `drop_image_placeholder_lines`；
2. **判定规则（三个条件同时命中才丢，缺一不可）**：
   - a. 行内含**第三人称指代机主**的词：`他`（作人称代词）/ `这人` / `这家伙` / `那家伙` / `那小子`；
   - b. 行内含**第一人称动作/心理动词组**：`我` 后接（折回|折返|回去|过去|去找|去看|回|走|跑|看|瞧|想|猜|琢磨|寻思|决定|打算|忍|憋|笑|叹|摇头|点头|翻|摸|掏|关|开|拿|放）之一；
   - c. 整行**不含 `你`**——她对机主说话用"你"，含"你"就是在对他说话，一律放行（防误杀的保险丝）；
3. 用常量正则/词表实现，词表做成模块级常量并在注释里写明来源（S1 真实翻车句 + 同类句式枚举），方便以后按新翻车句扩充；
4. 接入 `parse_reply`：位置与图片占位符滤网同段（切句**之前**），主聊（source="reply"）与主动消息（source="proactive"）两条通路都生效——旁白病两条路都可能犯；
5. 丢弃时记 INFO 日志（内容 + 来源），格式对齐图片滤网；丢完不许留下空气泡段（丢弃后产生的空行/空气泡按现有清理逻辑收掉，若现有逻辑兜不住要补，并配测试）。

## 任务 2：测试（tests/test_fixes19.py）

1. **命中用例**（必须丢）：
   - S1 真实翻车原句："这人嘴硬，我折回去看看。"；
   - 同类句式枚举至少 5 条（"他还是老样子，我去看看他。""这家伙又熬夜，我决定明天说说他。"等，按任务 1 词表造句）；
   - 多行文本中旁白行与正常行混合：只丢旁白行，正常行逐字保留；
2. **放行用例**（误杀防线，必须留）：
   - 含"你"的行："他说今晚不来了，你别等了"（转述第三人称但在对他说话）；
   - 正常对话行："我折回去拿了趟东西，累死我了"（无第三人称指代）；
   - 行内夹杂旁白句式但不是整行的（宁漏勿错纪律的兑现）；
   - 表情包段、`[沉默]`、普通短气泡不受影响；
3. 两条通路（reply / proactive）各至少一个用例；丢弃后无空气泡残留的用例；
4. 全部本地构造文本，禁止真实 API。
