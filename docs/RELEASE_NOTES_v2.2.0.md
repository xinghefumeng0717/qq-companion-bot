# v2.2.0

主对话收敛成一条主链，目标只有一个：**她说了什么、实际发了什么、存了什么、下一轮读到什么，四者一致。**

## 变化

- **只剩一条链路**：文字、表情、引用、图片和主动消息都走同一条主链。旧回复流水线、`use_kernel` 开关、多候选、首句裁剪、生成后质检和模型补救语音全部移除。
- **先存你的话**：消息一到就入库；她的话确认送达后才入库；发到一半停机，已送达的部分照样保存。
- **历史窗口**：模型每轮读到最近 10 轮对话。
- **语音**：发不发在她动笔前就定好并告诉她；只认"讨要"的说法，单纯提到"语音"不触发；哪一句是语音发的、哪次没发出去，会作为投递记录跟在那一轮对话后面；没发出去的下一轮补发一次，你说不要或超过 30 分钟就作废。
- **道别后不追**：你说了去忙、去睡之后只补一个表情，这一轮她不回。
- **表情带含义**：你发的小黄脸会带一句意思再给她看。
- **记忆**：日记带写下的日期；同一件待跟进的事不重复记。
- **排查**：模型侧和投递侧记在同一个 `trace_id` 下，并记录接口实际返回的模型名。
- **测试**：从 80 多个文件精简到 42 个。主链行为集中在 `tests/test_main_chain.py`，用真实数据库和真实投递器。
- **文档**：README 重写；原理篇更新了消息旅程、回复节奏、提示词拼装和语音四节及配图。

## 随旧流水线一起移除、目前没有的

- 她主动发表情包和 QQ 小黄脸；
- 平常回复时自己挑一句发语音（明确要语音、或她主动找你时仍会发）；
- 回复前先晾一会儿，以及平常回复前的"正在输入"提示。

## 升级注意

- 没有可以切回旧链路的开关。升级前请备份代码目录和 `data/companion.db`，出问题时恢复备份。
- `config.toml` 里旧的 `use_kernel`、`self_check`、`continuity_check`、`trim_echo`、`candidates`、`vision_direct` 等字段不再使用，留着不影响启动。
- 无新增第三方依赖，无需手动迁移数据库。
